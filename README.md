# Online Retail Sales Analysis

An exploratory data analysis project using Python and the UCI Online Retail dataset. The project examines transaction data to identify sales trends, product performance, country-level revenue patterns, and cancellations.

## Project Overview

The analysis includes:

- **Data Cleaning:** Handling missing values, duplicates, invalid prices, and inconsistent records.
- **Feature Engineering:** Creating monthly and weekday features, calculating revenue, identifying cancellation records, and grouping products into price categories.
- **Data Visualization:** Exploring sales trends, product and country comparisons, price distributions, numerical relationships, and cancellation patterns.
- **Business Insights:** Interpreting findings and suggesting practical business recommendations.

## Tools & Libraries

- Python
- Pandas and NumPy
- Matplotlib and Seaborn
- Plotly
- Jupyter Notebook

## Dataset

**UCI Online Retail Dataset**

The dataset contains 541,909 transaction records from a UK-based online retailer, covering December 2010 to December 2011.

Source: [UCI Machine Learning Repository – Online Retail](https://archive.ics.uci.edu/dataset/352/online-retail)

The dataset is not included in this repository. Download it from the source and save the CSV file as `online_retail.csv` in the project directory before running the notebook.

**Dataset citation:** Chen, D. (2015). *Online Retail* [Dataset]. UCI Machine Learning Repository. https://doi.org/10.24432/C5BW33.

## Running the Project

1. Clone or download this repository.
2. Install the required libraries using `pip install -r requirements.txt`.
3. Download the dataset and place `online_retail.csv` in the project directory.
4. Open `online_retail_analysis.ipynb` in Jupyter Notebook or VS Code.
5. Run the notebook cells in order.

## Project Purpose

This project was completed as part of a Business Data Analysis course to apply data cleaning, feature engineering, exploratory analysis, visualization, and business interpretation skills to a real-world dataset.
